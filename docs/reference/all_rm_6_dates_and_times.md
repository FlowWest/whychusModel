# historical RM 6 instream temperature - not summarized daily

RM 6 historical instream temperature - hourly. Data represents the
average of 1-3 loggers that are placed instream.

## Usage

``` r
all_rm_6_dates_and_times
```

## Format

75,514 x 2 data frame

- `date: `2012-04-23 - 2025-10-17

- `temperature: `hourly instream temperature collected by UDWC, degrees
  C
