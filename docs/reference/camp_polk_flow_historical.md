# Historical discharge at Camp Polk

Daily discharge data collected by the Oregon Water Resources Department
(OWRD) at the Camp Polk monitoring station (station 14076100) on the
Whychus

## Usage

``` r
camp_polk_flow_historical
```

## Format

A data frame with 5,469 rows and 3 columns:

- `date: `2011-05-01 - 2026-04-20

- `statistic: `mean

- `flow_cfs: `instream temperature collected by OWRD, degrees C

## Source

Oregon Water Resources Department Near Real-Time Hydrograph:
<https://apps.wrd.state.or.us/apps/sw/hydro_near_real_time/>
