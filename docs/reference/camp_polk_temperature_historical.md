# Historical instream water temperature at Camp Polk

Daily instream water temperature data collected by the Oregon Water
Resources Department (OWRD) at the Camp Polk monitoring station (station
14076100) on the Whychus combined with UDWC logger data at the same site

## Usage

``` r
camp_polk_temperature_historical
```

## Format

A data frame with 21,135 rows and 3 columns:

- `date: `2012-05-29 - 2026-04-20

- `statistic: `mean, median, max, min, 7DADM

- `temperature: `instream temperature collected by UDWC and OWRD,
  degrees C
