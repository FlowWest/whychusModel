# historical RM 6 instream temperature

RM 6 historical instream temperature - daily statistics

## Usage

``` r
rm_6_historical
```

## Format

9968 x 3 data frame

- `date: `2012-04-23 - 2025-10-17

- `statistic: `mean, median, max, min, 7DADM

- `temperature: `instream temperature collected by UDWC, degrees C
